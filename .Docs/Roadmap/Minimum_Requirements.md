# Minimum requirements for a TDD coding Team

## Work flow
1. Orion reads my requirement for a request run it through CDP full ask clarifications
2. After I provide what I can and Orion breakdown my requirements into Features and tasks
2. I review the feature and task and see if it meets my expecations, after revisions
3. Orion runs the first feature through CDP Full again and ask for clarifications
4. After which, it breaks down the tasks into subtasks that has less than 3 steps, if possible
5. The subtasks along with any context is passed along to Tara for testing
6. Tara reviews subtasks and run it through CDP v1, ask for clarification
7. Once Orion provides clarifications, Tara codes tests until it runs red
8. Wraper notices Orion, Orion assigns task to Devon, assign next availbalt test to Tara
9. Repeats until this is done
